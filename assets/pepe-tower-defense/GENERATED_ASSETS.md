# Generated Tower Defense assets

Created with the built-in imagegen tool; no API/CLI fallback used. Original generated PNGs are preserved alongside optimized WebP runtime derivatives. Runtime optimization only resizes/compresses; it does not repaint the assets. PNG originals are also preserved in the generation output folder. The command panel is opaque; goblin PNGs and WebP derivatives preserve true alpha.

- goblin-raider-v1.png / .webp: original goblin raider, runtime width 256px.
