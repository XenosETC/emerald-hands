# Pepe Wars artwork audit — October 11, 2026

The runtime now uses 13 raster assets: four player classes (miner, brawler, archer, mage), three enemies (grunt, runner, brute), three deposit sizes, the lane arena, and two generated citadel bases. Existing character/deposit/arena files remain unchanged. The newly generated bases use true alpha transparency and retain their original output files. They render at 170 × 170 beneath the live base labels/health bars; original procedural bases remain a loading/failure fallback. No gameplay, damage, economy or save rules changed.

The base sprites were generated with the built-in imagegen tool. Existing Brawler and Corrupt Grunt sprites were style references. Earlier assets have been visually/structurally inspected here, but their original generation provenance is not asserted by this audit.
