# Temple Run rendering and Soul World Warp Step — October 17, 2026

Temple Run now defaults to Balanced graphics: 1.25 maximum 3D pixel ratio with live shadow maps disabled. On a device previously rendering at ratio 2, that allocates about 61% fewer 3D pixels; this is an allocation comparison, not an FPS measurement. Smooth caps the 3D ratio at 1. High retains the previous ratio-2 cap and live shadows. The soft contact shadow remains in all modes. The selector is accessible, does not reset a run, and yields form keyboard input instead of triggering game actions. The preference is page-local and resets to Balanced on reload. No browser settings or hardware acceleration settings were modified.

The paused 3D scene now renders once, then sleeps until dimensions, density, shadow mode or run state changes. Simulation timing, routes, collision and saves are untouched. Unit tests verify cost profiles, invalid density fallback and pause invalidation; all runner gameplay replays remain intact. Character renderer diagnostics now report the selected shadow state honestly.

Soul World's Warp Step previously used a green sepia filter for its afterimages. The filter is removed, echo lighting alternates violet/cyan, the travel body retains 70% opacity, and cyan/violet/gold curved trails and bounded particles add color. Reduced effects keep a single trail, reduced particles and no echo blur. Timing, range, damage, Spirit costs and both normal/practice saves are unchanged. Tests execute a real Warp phase and the actual renderer effect handler, checking palette, phase boundaries, particle counts and unchanged simulation. Existing saved GIFs are preserved; tools/warp-color-preview.mjs produces a new 75-frame 50fps preview (1.5 seconds, actual 340ms Warp) under pepe-soul-world/docs/warp-color-2026-10-17. This preview uses the actual simulation/renderer on an empty map; it is not a Chrome performance benchmark.

Browser QA used an isolated local origin on port 4187. Chrome was unavailable to the browser tools, so verification used the in-app browser. Temple Run native start, right-button keyboard activation and pause reached 118 m. Smooth and High switched while paused; the 390px Focus layout had no horizontal overflow and no observed console errors. temple-smooth.png and temple-high.txt capture the UI. Soul World's isolated practice run cast Warp with K, spent 20 Spirit and moved from x=320 to x=560 with no console errors; warp-native.png and warp-native-result.txt record that native check. No browser game state was assigned. The user's existing practice origin was untouched.

Remaining gate: measure sustained FPS and confirm feel on the user's Chrome/device. The changes reduce known rendering work but do not establish a particular FPS gain. Hosted deployment was not verified.

Exact staged-copy validation passed 256 arcade, 36 Temple Run and 263 Soul World tests (555 total). Working-tree suites also passed after the fixes.
