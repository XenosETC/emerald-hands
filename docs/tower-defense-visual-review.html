PLAYABLE SUPPORT DEFENDER

Pepe Alchemist

Crack armor. Set up the kill.

A chemical-support defender for armored goblins. Its amber-green flask weakens armor briefly so nearby damage towers can finish the target.

Goggles, apron, condenser and potion vessels distinguish it from the hooded Mage. The jade-and-gold lab turret keeps it in the same roster.

Base specificationStarting point for testing
Build cost135 defense shards
Attack15 damage; 0.95s base interval (0.88s at level 1); 150 range; one target
Armor weakeningReduce ordinary armor by 10 percentage points for 2 seconds; bosses by 5 points. Refresh duration without stacking. No effect below zero armor.
