# Pepe Temple Run

Playable browser prototype inspired by the three-lane runner loop of Subway Surfers. Crown Pepe escapes an original jade temple setting. Three.js moving perspective causeway with the October 3 rebuilt Pepe Rumble gameplay-preview Crown mesh, its exported 32-bone skeleton, and baked animation clips plus an isolated runner crouch clip. The normal renderer uses a modeled 3D runner world with procedural sky, jungle, ruins and water; this is a bounded runner prototype rather than a persistent explorable world.

Open `/pepe-temple-run/index.html` through the arcade development server (`npm run dev`). Arrow keys or WASD move, jump and slide; Space jumps; Escape pauses; Enter starts/restarts. On phones, swipe the playfield or use the four buttons.

Includes stone idols, broken bridges, low gates, jade trails, a 10-second magnet, a one-hit crown shield, increasing speed, optional synthesized sound, and an independent best-distance save (`pepe-temple-run-v1`). The first clean frog gate opens the Corrupt Frog Temple, with a carved Blender portal, corrupted surroundings, separate shard rewards and dodge-only crystal thorns. Fixed-seed obstacle patterns leave an open lane. The opening teaches jump, slide and dodge; later rows alternate hazards with adjacent clear routes. Collection trails guide the route, streaks show combo feedback, and milestones appear every 250 m. Row spacing contracts from 80 m to 52 m as pace builds. Jade and shards are run-only; no shop or persistent currency balance.
